Revisaremos el código que hicimos Patrick y yo para el mini curso de QLab como clase introductoria a RStudio, utilizando R Markdown para ello.

Este trabajo consisitía en un análisis de datos utilizando las bases de datos ENAHO o ENDES del 2023. 
Debíamos seleccionar un módulo específico dentro de una de estas bases de datos: salud o educación en el caso de ENAHO, o disciplina infantil o mortalidad materna en el caso de ENDES. 
A partir de esta selección, realizar un análisis exhaustivo que incluirá la limpieza de datos, la configuración de variables, la generación de estadísticas descriptivas, y la presentación de gráficos que permitan una interpretación clara de los resultados obtenidos.
